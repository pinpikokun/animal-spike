# 原作スプライト分割サンプル (ドット打ち参考用)

元データ: assets/reference/vb2211/*_sheet.png (原作VB22.DATから抽出、32x32セル)
用途: ドット打ちの姿勢参考。製品には同梱しない。

**このコマ割当は VB22.EXE の逆アセンブルで確定した原作準拠版** (2026-07-20)。
状態機械とスプライト描画コードから全24セルの用途を特定した。
詳細な証拠は docs/reference/original-vb22.md の「スプライトセル対応表」参照。

## キャラフォルダ (全8体共通のコマ順)

tome / hito / piyo / ume / carby / duo / alien (=SEC1) / uma (=SEC2)

| フォルダ | セル | 内容 | アニメ周期 |
|---|---|---|---|
| idle_walk | 0,1 | 立ち=歩き共用 (2コマ交互) | 歩行も同じ2コマ |
| jump | 2 | ジャンプ (上昇姿勢) | |
| attack | 3,4,5 | 空中アタックスイング3コマ | 2tick/コマ、4↔5で終端 |
| receive_stance | 6 | レシーブ構え (下+ボタンのしゃがみ) | |
| toss | 7 | トス (ボールを真上に打ち上げ) | |
| ground_swing | 8,9 | 地上打撃スイング (トス/レシーブの実打) | 逆回し8→7→6もある |
| dive_receive | 10,11 | 横っ飛びぎりぎりレシーブ | 11→10→7→0 の順 |
| knockback | 12 | 強打被弾 (吹っ飛び) | |
| shock | 12,13 | 感電 (サンダーボール被弾) | 3tickごと12/13交互 |
| stun | 14,15 | 気絶 | 3tickごと交互、125tickで解除(連打で短縮) |
| burn | 16,17 | 炎上 (燃えるアタック被弾) | 3tickごと交互 |
| fly | 18,19,20 | 羽ばたき (飛行キャラ用) | 18,19,20,19ピンポン3tick/コマ。ホバー=18固定 |
| bubble | 20 | 泡 (バブルパック被弾) | 飛行キャラのみセル4を代用(20は羽ばたきと衝突するため) |
| victory | 21,22 | 勝利 | 毎フレーム交互 |
| fall_special | 23 | 特殊吹っ飛び後の垂直落下 | 用途は状況証拠(有力) |

- セル12は knockback と shock、セル20は fly と bubble で共用 (原作仕様)。
- 左向きはデータに存在しない。EXEが描画時にセル+24指定で左右反転する。
  自作でも「右向きだけ描いて表示層で反転」で原作準拠になる。

## 自作ドットを打つときの注意

- 現行ゲームのボール実寸は 28x28 (assets/ball/volleyball_game.png)。
  原作の32x32とはキャンバスが違うので、拡大流用ではなく描き直しになる。
- キャラの自作は 1枚シートでなくアクション別フォルダ形式を推奨
  (assets/characters/mario/ と同じ形式。コマ数は自由に増やせる)。
- 炎などの「まとうもの」はボール本体に描かず fx として分離する方針
  (詳細: docs/superpowers/specs/2026-07-20-controls-drive-gauge-damage-design.md)。
