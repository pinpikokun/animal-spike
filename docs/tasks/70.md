# #70 操作体系の原作準拠化

Status: 2026-08-01実装完了。人間による試遊だけ未実施。

## 最終結果

- 空中の上+ボタンを通常アタック、下+ボタンをジャスト可アタックに分離した。
- 前+ボタンを地上・空中共通ブロックにし、条件外では前トスへ戻した。
- 空中トスを自陣後方、自陣前方、敵陣の3方向へ分けた。
- 3打目は横入力に関係なく敵陣へ返す。
- CPUも残りドライブに応じて上下アタックを選び、空中では前+ボタンでブロックする。
- 成功ブロックは地上・空中とも同じ姿勢を表示する。原作キャラはセル9を使う。

最終操作の正本は `docs/gameplay-controls.md`、決定根拠は
`docs/superpowers/specs/2026-07-25-controls-original-restoration-design.md` とする。
