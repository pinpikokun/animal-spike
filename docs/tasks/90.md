# 6. #90 前トス姿勢が死んで全キャラのtoss_fwd素材が表示されない

**中身**: `hit_kind` は「0=レシーブ、1=トス、2=前トス」と定義されているのに、
実際は0と1しか代入されない。表示側は `==2` の分岐を持っており到達不能。
全キャラ分用意した前トスの絵が一度も画面に出ない。

**根拠**: 実測。`hit_resolver.gd:467,478` の代入が0と1のみ、
`anim_select.gd:26` が `==2` を見ていることを確認。

**なぜP3の5位か**: #70 で地上トスが3ゾーンになるので、**そちらと合わせて判断する。**
前トスを姿勢として復活させるか、絵ごと撤去するかは操作体系が決まってから。
