# 3. #98 キャラごとの能力ランクと付与能力を決める（共同設計会）

**中身**: A〜Eの5能力（パワー/ジャンプ/スピード/ブレーキ/ガード）を誰にどう割り振るか、
付与能力（トス上手・レシーブ上手・むらっけなど）を誰に付けるかを決める。
13体中5体は既に個別ランクを持ち、8体が全ランクCのまま。
付与能力で有効なのは5つだけで、13個は名前だけの休眠。
ユーザーが例に挙げた「サーブが上手い」に相当する能力は存在しない。

**根拠**: 実測。`character_profile.gd` の PROFILES を数え、全ランクCが8体、
個別ランク持ちが5体であることを確認。
**当初「全キャラ全ランクCで性能差がほぼ無い」と書いたのは誤り。訂正済み。**

**なぜP3の3位か**: #89 で軸を直してから。#97 のキャラが決まるとさらに増えるので、
先に既存13体の割当を通しで決めておく方が後が楽。

**2026-07-26 追加の決定事項**: **「サーブが慎重」をキャラの性能として割り当てる。**
原作はサーブの試し打ちの見積もりを**キャラ番号の偶奇**で変えていた
（`0x954F`〜`0x9577`。奇数番号は急降下で試すため中央を諦めて奥へ回りやすい）。
番号の偶奇に中身の理由が無く、本作のキャラ番号は原作と対応しないため移植しない。
**代わりに、誰が慎重かをここで意味づけて決める。**（ユーザー決定）
