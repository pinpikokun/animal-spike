# 2. #104 前衛CPUがブロックとアタック返しを使い分ける（本作独自）

**中身**: 飛んでくるアタックに対し、前衛のCPUが「ブロック」と「アタック返し」を
状況で使い分ける。**本作独自仕様（2026-07-26 ユーザー決定）。**

**根拠**: 実測（`tests/zz_counter_attack.gd`）。速いアタック球（582px/s）を撃ち込んでも
**CPUは24回中0回しか跳ばない。反応遅延を0にした最強でも0回。**
「気づくのが遅い」のではなく、**飛来アタックに跳びかかる判断そのものを持っていない。**

**原作との関係**: 原作は「アタックはアタックで返せません」（DOC 124行目）。
ただし必殺技だけは例外で「アタックで返すと技はかき消される」（253行目）。
コード上もボール種別10〜13（重力を持たない必殺技系）だけがアタック不可（`0x610B`）。
**本作が普通のアタックまで返せるのは原作から外れているが、それを持ち味として活かす方針。**

**なぜP2か**: 遊んだときの面白さに直結する。ただし #70（操作の割当）で前提が変わりうるため、
#70 と一緒に設計すること。
