# 2. #89 定義のないキャラ差キー3つが物理式で黙って無効化されている

**中身**: `just_window`（ジャスト判定の窓の広さ）、`absorb`（トス時に入射の勢いをどれだけ殺すか）、
`just_reward`（ジャストアタックの上乗せ威力）——この3つが物理の式に掛かっているのに、
値がどこにも定義されていない。値を引く関数が「知らないキーなら100を返す」ため
エラーにならず、**全キャラ同じ値で素通りしている。**

**根拠**: 実測。`chars.gd:132-150` の `stat()` の分岐と、
3キーが `chars.gd` / `character_profile.gd` / `rules.json` のどこにも無いことを確認。

**なぜP3の2位か**: **キャラに個性を割り振る前に、個性を乗せる軸を直しておく必要がある。**
軸が繋がっていない状態で割当だけ決めても効かない。#98 の前提。
