# 5. #83 性能の見張りテスト（1コマのコスト上限）

**中身**: 1コマのシミュレーションのコストが決めた上限を超えたらテストが落ちる仕組み。
重くなった日に気づけるようにする。

**根拠**: 実測。1コマ 205,566ns、60fps の1フレーム予算 16,666,666ns。
巻き戻し8コマで予算の10.5%、16コマで21.0%。

**なぜP0か**: 安い。そして直後に #82（仮想打球テスト）を入れる予定で、
これは予測ループを1打あたり数本増やす変更なので、**見張りが先に無いと劣化に気づけない。**
遅いPCでは3〜4倍遅くなるため、余裕は見た目ほど大きくない。
