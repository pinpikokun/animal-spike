# #113 地上トスとレシーブの攻撃球防御差を再設計する

## 発見

原作は、攻撃球を下+ACTIONのレシーブで受けるとダメージ40%、下なしの地上トスで
触ると通常ダメージになる。下入力には「制御を捨てて防御を選ぶ」意味がある。

本作も地上入力を次のように分類する。

- 下+ACTION: 通常レシーブ。時間窓などを満たした場合だけジャストレシーブ。
- 下なしのACTION、左右+ACTION: すべて地上トス。左右はトス方向を選ぶ。

ここでいう「体力」は画面上のガード、コード上の `guard` を指す。ドライブゲージとは
別の資源であり、現行挙動を混同してはならない。

## 現行挙動

### 通常アタック球

`ball_attack_kind=BALL_ATTACK_NORMAL` かつパワー球でない通常アタックを受けた場合:

- 通常レシーブ: ドライブを1本削られる。ガードは削られない。
- ジャストレシーブ: ドライブもガードも削られない。
- 地上トス: ドライブもガードも削られない。

### ジャストアタック由来のパワー球

`ball_attack_kind=BALL_ATTACK_JUST`、`ball_power=1` の球を受けた場合:

- 通常レシーブ: ドライブを2本削られる。さらに `ball_guard_damage` 分だけガードを
  削られ、しりもちと後方への吹き飛びが発生する。
- ジャストレシーブ: 防御可能な球なら、ドライブ削り、ガード削り、しりもちをすべて
  無効化する。ガードの回復はしない。
- 地上トス: ドライブは削られない。接触がスイート範囲内なら、防御可能なパワー球の
  ガード削りとしりもちも受けない。スイート範囲外ならガードを削られ、しりもちと
  吹き飛びが発生する。

### 防御不能球

- 燃える球などの防御不能球は、入力窓やスイート範囲内でもガード削りと専用被弾を
  無効化できない。
- 通常レシーブでのドライブ削りの有無と量は、その球が持つ `ball_attack_kind` に
  従う。現行の燃える必殺技球は `ball_attack_kind=BALL_ATTACK_NONE` のため、ガードを
  固定40削って炎上を起こすが、ドライブは削らない。

## 問題

現行テスト `test_toss_and_attack_return_do_not_take_incoming_drive_damage` は、地上トスが
攻撃球のドライブ削りを受けないことを固定している。一方、通常レシーブは通常
アタックで1本、ジャストアタックで2本を削られる。さらにパワー球では、通常
レシーブが接触位置にかかわらず非ジャスト扱いとなるのに対し、地上トスはスイート
範囲内ならガード削りとしりもちまで防げる。

したがって現状は、下+ACTIONの通常レシーブより、下なしの地上トスを芯で当てる方が
防御面で有利になり得る。これは原作の「下入力で防御を選ぶ」という意味と逆転して
おり、操作の直感にも反する。

## 着手時に決めること

1. 相手攻撃球へ地上トスを出した場合、通常レシーブより安全でよいか。
2. 下+ACTIONを明示的な防御選択として残すか、相手球では自動レシーブにするか。
3. 地上トス、通常レシーブ、ジャストレシーブのドライブ・ガード・吹き飛び差。
4. トスを危険にする場合、原作の通常ダメージを本作のどの資源へ対応させるか。
5. 操作説明とアニメで、トスとレシーブの選択結果をどう伝えるか。

## 非目標

- 三段階レシーブの高さ調整へ便乗して防御経済を無断変更すること。
- 原作の40%を、本作の異なるゲージ体系へ根拠なく直訳すること。

## 着手条件

三段階レシーブの実装と試遊が終わった直後の次タスクとして着手する。ACTIONのみの
地上トスと下+ACTIONの通常レシーブを相手攻撃球へ使い分け、どちらが実戦上の最適解に
なるかを確認してから設計する。
