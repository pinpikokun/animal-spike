# 7. #99 既存実装の数値に根拠があるかの横断監査

**中身**: 実装の中に散らばっている数値のうち、**根拠のあるもの（原作・実測・実プレイの
判断）と、誰かが何となく決めたもの**を仕分ける。根拠の無いものは印を付けて、
実プレイで決め直す候補にする。

**根拠**: 実測。2026-07-26 だけで、根拠の無い数値が原因の事故が2件起きている。
スパイクの速度を設計書へ書くとき掛け算を見落としてゲームが壊れた件と、
「ネットから120px以内」という線引きが対で2箇所にあり片方だけ消すと
ブロッカーが跳ばなくなる件。**どちらも「なぜその数字なのか」が書かれていなかった。**

**なぜP4か**: 効果は大きいが範囲も大きい。ゲームの中身（P2）を先に固めてからやる。
