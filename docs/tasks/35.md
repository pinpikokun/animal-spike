# 2. #35 CPU傾向学習（1試合内適応）

**中身**: サーブ方向と攻撃コースを数え、閾値を超えたら**守備配置をシフト**する。
反応速度は上げない（理不尽になるため）。
同じ手を繰り返すと通用しなくなる仕組みで、**人間を勝たせるためのものではない。**
調査書は「スコア差には絶対に連動させない」と明記している。

**根拠**: 実測。調査書の該当項（ADAPT_COUNTER）を自分で読んでいる。
**当初「劣勢なら手加減する等」と説明したのは Claude Code の作り話で、誤り。**
調査書が名指しで禁止している内容だった。

**なぜP5の2位か**: CPUの土台（#66 / #82 / #85）が固まってから。
