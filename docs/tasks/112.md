# #112 上級者向け速攻トスを設計する（将来タスク・未設計）

## 目的

低いトスを、慣れたプレイヤーが意図して使う速攻の選択肢として設計する。

## 今回決まった境界

- 人間向け標準トスの高さ調整とは分離する。
- 標準トスへランダムな低下を混ぜない。
- CPU難易度や `トス上手`、`トス下手` のパッシブ能力とは一旦切り離す。
- まず標準トスの初回試遊と最終調整を完了させ、その高さとテンポを比較基準にする。

## 着手時に決めること

1. プレイヤーが速攻トスを意図して出す入力方法。
2. 標準トスとの高さ・滞空時間の差。
3. 打つ側の難しさと、守る側が反応しにくい利点の釣り合い。
4. CPUが使用するか。使用する場合は強さをどう表現するか。
5. パッシブ能力と結び付けるか。
6. 既存の `toss_vy_for_apex_pct`、`_toss_apex_pct`、`SALT_TOSS_BAD` を再利用するか、
   別方式へ置換または撤去するか。
7. 人間が成功・失敗を納得できる表示と検証方法。

## 非目標

- 標準トスの調整と同時に実装すること
- 確率だけで人間やCPUを失敗させること
- 入力方法を決めずに低い軌道だけ追加すること

## 着手条件

`docs/superpowers/specs/2026-07-30-human-friendly-standard-toss-design.md` の標準トスを
ユーザーが試遊し、最終値が確定していること。
