# #111 低速PCのロールバック上限とsnapshot最適化

**優先度:** P1

## 問題

#83の基準機ではSimRoot担当範囲の1stepが約153,000ns、16コマ下限見積りが約2.45msだった。
3〜4倍遅いPCでは約7.3〜9.8msとなり、4倍側は60fpsの半フレーム8.33msを超え得る。

旧分解計測ではsnapshot保存が約88,000nsで、stepの主要コストだった。
#83は同一基準機で大幅な退行を止めるゲートであり、対応機種の保証や最適化は扱わない。

## 完了条件

1. 対象とする低速PC帯を実機または同等条件で測定する。
2. 許容する最大巻き戻しコマ数を決める。
3. SyncManager固定費を含む実ロールバック全体を測る。
4. snapshot保存の内訳を測り、必要なら直列化や保存頻度を最適化する。
5. 60fps予算に対する合格条件を設計書へ固定してから実装する。

## 非目標

- #83の上限を低速機向けに無断で緩めること
- 実測なしに対応機種や最大巻き戻し数を決めること
