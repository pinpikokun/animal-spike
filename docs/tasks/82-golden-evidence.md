# #82 ゴールデン更新根拠

## 対象変更

ジャンプサーブの空中打球入力を固定入力から通常の空中打球選択へ統一した。

- 旧: `IN_ACTION | IN_DOWN | fwd`
- 新: `_pick_air_shot(..., TRIAL_BAND_CURRENT_STEPS)`

通常の空中打球と同じ4方針、安全判定、決定論的な入力選択をサーブにも適用するため、意図した物理挙動変更である。

## 変異確認

設計が指定する政策甲の即時トス早期returnを別途一時的に無効化すると、全501テスト中3件が失敗した。対象の `test_jump_serve_uses_shared_three_candidates_and_four_policies` 自身が赤になり、ほかに政策甲の単体検査と空中入力検査も赤になった。`SCRIPT ERROR` は0件だった。変更を復元後、全件成功を再確認する。
