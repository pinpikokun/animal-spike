# #106 乱数2ワードの所有者を決める（#105 の後続）

## 症状

**原作では乱数の2ワードはプロセスの持ち物で、試合の持ち物ではない。**
本作では `Simulation.reset_match()` が試合開始のたびに `rng` と `aitick` を
書いている（`simulation.gd:478-480`）。これは #88a でテスト容易性のために
入れた逸脱であり、原作の構造ではない。

    9c00  mov ah,0x2c / int 0x21   起動時に1回だけ
    9c04  mov [RND], cx            RND = (時 << 8) | 分
    9c0b  mov [aitick], ax         aitick = RND
    以降、試合・セット・ラリーのどこにも再初期化は無い

詳細は `docs/tasks/88.md` の (d)。

## 本作で実際に起きること

`src/display/root.gd` に**ローカル再戦の導線が実在する**。

- オプションメニューの `restart_requested`（`root.gd:44-46`）
  → `_restart_to_select()`（`root.gd:61`）が GameView を破棄
  → `_start_local_game()`（`root.gd:50`）が**新しい GameView と新しい SimState** を作る
  → `game_view.gd:103` の `reset_match()` が走り、**2ワードが再初期化される**

原作なら2試合目は1試合目の続きの系列で始まる。本作は同じ値へ戻る。
**#105 で起動時の種を配線しても、この再初期化は残る。**

## なぜ #105 と分けたか

Claude Code と Codex が2往復して合意（2026-07-28）。

1. **1ワードの `seed` 引数では継承を表現できない。** 原作の2ワードは起動後に
   独立して分岐する（`RND = RND*7 + 0x4017 + aitick` は毎コマ、
   `aitick += RND` は打球時、`++` は役割入替時）。`reset_match(seed)` は
   1ワードから両方を作るので、「前の試合の続き」を seed へ入れる方法が無い。
   **配線ではなく契約の変更になる。**
2. **#105 単体は固定値を1つも動かさないが、継承は確実に動かす。**
   2つの理由が1つの値に乗ると、動いた原因を切り分けられない
   （CLAUDE.md「一つの変更に一つの理由、一つのコミット」）。
3. **#105 単体は決して退化しない。** 現状は毎試合・毎再戦が同一系列。
   起動時の種を入れれば少なくとも起動ごとに変わる。今より悪くなる場面が無い。

## 決めること

**正しい問いは「再戦で継承するか」ではなく「2ワードを誰が所有するか」。**

1. **所有者。** プロセスが持ち、試合はそれを借りるだけ、という形が原作の構造そのもの。
   その場合 `reset_match()` から `rng`/`aitick` への代入を外すことになる。
   テストは現在 `seed` 引数で初期値を与えているので、代替の与え方が要る。
2. **再戦の継承。** ローカル再戦で前の試合の終了時点の2ワードを引き継ぐか。
   引き継ぐなら、`root.gd` が破棄する GameView から値を取り出す経路が要る。
3. **リプレイの記録単位。** 途中の試合から再生するには初期種では足りず、
   **試合開始時の `rng` / `aitick` 2ワード**が要る。あるいはプロセス開始から
   全入力を再生する。どちらを採るか。
4. **デバッグビューは対象外。** `main.gd` は開発計器で原作に対応物が無い。
   固定種 0 の独立系列を維持する（#105 で確定済み）。

## #105 で先取りしてはいけないこと（Codex の指摘）

- 再戦でも同じ boot seed から再開することをテストで固定する
- `boot_seed` を `match_seed` や「乱数所有者」と命名する
- seed を `SimState` / state hash / ロールバック状態へ入れる
- seed だけで任意の試合を再生できるとリプレイ仕様へ固定する
- `reset_match()` へ2ワード継承や preserve モードを先回りで足す

## 着手の前提

#105 の後。固定値が動く変更なので、#105 の「固定値ゼロ」という強い検査を
先に成立させてから触る。
