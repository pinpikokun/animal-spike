# P3 — 内容物（キャラ・個性・素材）（7件）

## 1. #97 本番キャラ生成（トラックB）のゲートとキャンバスサイズ確定

いまゲームに出ているキャラは全て仮素材か原作からの借り物で、`sprite_factory.gd`の冒頭に「製品には同梱しない（差し替え前提）」と書いてある。
詳細: `docs/tasks/97.md`

## 2. #89 定義のないキャラ差キー3つが物理式で黙って無効化されている

`just_window`（ジャスト判定の窓の広さ）、`absorb`（トス時に入射の勢いをどれだけ殺すか）、`just_reward`（ジャストアタックの上乗せ威力）——この3つが物理の式に掛かっているのに、値がどこにも定義されていない。
詳細: `docs/tasks/89.md`

## 3. #98 キャラごとの能力ランクと付与能力を決める（共同設計会）

A〜Eの5能力（パワー/ジャンプ/スピード/ブレーキ/ガード）を誰にどう割り振るか、付与能力（トス上手・レシーブ上手・むらっけなど）を誰に付けるかを決める。
詳細: `docs/tasks/98.md`

## 4. #57 原作キャラ取り込み（残り7キャラ）

原作のスプライトをデコードして、残り7キャラをゲームへ入れる。
詳細: `docs/tasks/57.md`

## 5. #103 原作キャラの挙動再現（打ち分け例外・必殺技・固有の癖）

原作VB22.EXEに残っているキャラ固有の挙動を再現する。
詳細: `docs/tasks/103.md`

## 6. #90 前トス姿勢が死んで全キャラのtoss_fwd素材が表示されない

`hit_kind`は「0=レシーブ、1=トス、2=前トス」と定義されているのに、実際は0と1しか代入されない。
詳細: `docs/tasks/90.md`

## 7. #71 原作スプライト切り出し素材をコミットする

原作から切り出したスプライト素材をリポジトリへ入れる。
詳細: `docs/tasks/71.md`
