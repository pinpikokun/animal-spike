# 原作「VOLLEY BALL 2on2」Ver1.1 (1994, TOME) 仕様まとめ

一次資料: C:\work\PC98\vb2211\VB22.DOC(全文)と同梱データの解析。
フリーソフトウェア(作者が著作権保持、転載・配布自由と明記)。
原作スプライトは操作感確認用であり製品には同梱しない。

## ルール(DOC記載の確定情報)

- 11点先取、デュース有り(点数はオプションで変更可能)
- サーブはコート外から1回勝負。サーブのネット接触は原作既定で「触れてもよい」(禁止に変更可能)
- 同一チーム連続3タッチまで。同じ人が連続で打ってもよい
- ブロックも1タッチに数える(現行実装も原作準拠)
- コート左右は壁でボールは反射、アウト無し
- アタックを何度も受けると気絶する(耐久システムの原型)
- アタックはアタックで返せない。返す手段はレシーブ(ダメージ大幅減、制御不能)か
  ブロック(ダメージ半減+攻撃に転じる)

## 打ち方(入力体系)

- トス(地上ボタン): 方向なし=自陣前方へ、後=自陣後方へ、前=敵陣へ入る球
- アタック(空中で上or下+ボタン): 左右キーで3方向に打ち分け
- レシーブ(地上で下+ボタン)
- ブロック(ネット際で前+ボタン、空中でも地上でも可)
- 「押し打ち/離し打ち」: ボタン押しで打つ体制に入り、打つまでの間に
  離すか押し続けるかで技が分岐する(必殺技の入力に使用)

## データファイル解読結果

### スプライトDAT(15360B: TOME/HITO/PIYO/UME/CARBY/DUO/SEC1/SEC2、BALL)

フォーマット確定(scripts/decode_vb2211.pyで再現可能):
- 1スプライト=640B=[B,R,G,E 色4プレーン各128B]+[マスク128B(ビット1=透過)]
- 32x32ピクセル、1ファイル24スプライト
- 内容: 待機/歩き/ジャンプ/アタック/しゃがみ/後ろ姿/気絶/炎上/シャボン/勝利等の全ポーズ
- BALL.DAT: 通常球・回転・竜巻・炎球・雷球・シャボン等のエフェクト込み
- 解読画像: assets/reference/vb2211/(ALL_preview.pngが一覧)
- パレットはEXE内定義のため仮パレット(PC-98標準16色)。色味は原作実機と異なる可能性

### BACK.DAT(35840B=56セル、同形式)

タイトルロゴ「VOLLEYBALL 2on2」、ネット・コート罫線、PLAYER NAMEプレート、
全8キャラの顔アイコン(顔HUDの一次資料)。

### その他

- VB22.EXE(77KB): 16bit DOS MZ、Microsoft C 1989製。物理定数は逆アセンブル調査中
- FONT.DAT(2304B): 8x8フォント
- BGM1-4.O + TONE.DTA + NL.COM: FM音源BGMデータ+音色+常駐ドライバ(NL.COM=1992)
- V.BAT: NL.COM常駐→VB22.EXE起動のランチャ

## 現行実装との主な差異(判断待ち項目)

- ブロックのタッチ数: 原作・現行ともに数える
- サーブ: 原作=場外から助走なし1回、現行=2段階(トス→打撃)
- 11点先取は2026-07-19採用済み(コミット80aaeb1)
- ボール物理: 現行版と原作版をプロファイル切替で比較予定(ユーザー指示)

## CPU難易度(2026-07-20ユーザー指示: 調整再開前に必ず実施)

CPUの強さを本調整する段階になったら、先にVB22.EXEを逆アセンブルして
OPTIONの「GAME LEVEL」が実際に何を変えているか(反応速度/ミス率/技頻度等)を
確認すること。判明済みの手がかり:

- DOC: OPTIONにGAME LEVELの1軸設定。ランキング総合点のLEV項にも使用。効果詳細は未記載
- 1P/2Pは勝ち抜き戦のため、相手キャラ構成自体が難易度カーブを兼ねる
- 0x1EF2にCPU用弾道シミュレータ(実物理と同式の先読み=現行AB_PREDICT相当)
- レベル変数の参照箇所は未調査。ここを追えば原作の難易度調整方式が確定する

## スプライトセル対応表(2026-07-20 EXE逆アセンブルで確定)

VB22.EXEの状態機械とスプライト描画コードから全24セルの用途を特定した。
描画関数0x292e(セル%24で640Bオフセット、セル+24=左右反転描画)、
セル番号配列DS:0xe92への全書き込み(約50箇所)と状態ディスパッチ
(0x7bc8-0x7c8c、状態=[0xe78])の読解による。

| セル | アクション | 備考 |
|---|---|---|
| 0,1 | 立ち=歩き共用(2コマ交互) | 歩き専用コマは存在しない |
| 2 | ジャンプ(上昇姿勢) | |
| 3,4,5 | 空中アタックスイング | 2tick/コマ、終端は4と5交互 |
| 6 | レシーブ構え(しゃがみ) | 状態0xe |
| 7 | トス(真上打ち上げ) | |
| 8,9 | 地上打撃スイング | 逆回し8,7,6の遷移もある |
| 10,11 | 横っ飛びレシーブ | ボールx±0x18内で発動、11,10,7,0の順 |
| 12 | 強打被弾(吹っ飛び) | 感電と共用 |
| 12,13 | 感電(サンダーボール被弾) | 3tickごと交互 |
| 14,15 | 気絶 | 3tick交互、125tickで解除、連打で短縮 |
| 16,17 | 炎上 | 3tick交互 |
| 18,19,20 | 羽ばたき(飛行キャラ) | 18,19,20,19ピンポン。ホバー=18固定 |
| 20 | 泡(バブルパック被弾) | 飛行キャラのみセル4を代用(有力な解釈) |
| 21 | 勝利ポーズ | 静止画、非ループ |
| 22 | 敗北ポーズ | 静止画、非ループ |
| 23 | 特殊吹っ飛び後の垂直落下 | 有力(状況証拠2箇所) |

セル21と22は連続アニメではなく、勝者は21、敗者は22を静止表示する。

副産物: 左向き絵はデータに無くEXEが+24指定で反転描画。泡中はボール側が
セル22/23交互(泡エフェクト)。気絶解除はボタン連打で加速(+3/押下)。

現ゲームbuild_original()の旧割当はwalk=2/toss=3/jump=8/attack=9/crouch=10/
hurt=11が誤りと判明(タスク#64で修正予定)。
