# VB22.EXE 静的解析レポート (ボール物理定数抽出)

対象: C:\work\PC98\vb2211\VB22.EXE (77614 bytes, MZ, Microsoft C 1989, PC-9801)
DGROUP(データセグメント) = パラグラフ 0x11EE (ファイルオフセット 0x200+0x11EE0+DSオフセット)。
コードはセグメント0のオフセット、変数はDSオフセットで表記。
座標・速度は全て整数word、固定小数点なし(シフト量0)。浮動小数点は威力→スタミナ計算のみ(8087エミュ)。

## 1. 重力 (確度: 高)
- ボール重力 = +5/frame。変数[0x1182]、0xBA78で設定。更新: 0x3F84 y+=vy; vy+=g
- プレイヤー重力 = +6/frame。変数[0xE6E]、0xBA7Eで設定。更新: 0x6FCF
- ボール落下速度上限 = 32 (0x455B)

## 2. 座標系 (確度: 中)
- ボール: state=[0xEB4] x=[0xEB6] y=[0xEBA] vx=[0x1130] vy=[0x1132] (表示コピー 0x10C2/0x10C6)
- プレイヤー(4体=2vs2): char=[bx+0xE84] state=[bx+0xE78] x=[bx+0x116E] y=[bx+0x1176] vx=[bx+0x10DE] vy=[bx+0x1124]
- X: 壁4〜148、ネット中央x=76(0x4C)、ネット帯72〜80。1単位≈4px (描画時x/2をバイト列単位で渡す, 0xC301)
- Y: 下向き正。ネット上端y=258(0x102)、プレイヤー接地y=288(0x120)。1単位≈1ライン
- サイド符号テーブル DS:0x42 = {+1,-1}

## 3. 反射 (確度: 高) コード0x455B〜0x47CA
- 壁/ネット側面: |vx|>1なら vx=-vx/2 (反発率0.5)、|vx|==1なら vx=-vx
- ネット上端: vy=-vy/2。vx==0なら乱数で落下側決定、ネットから離れる向きにvx±1。|vx|>4ならvx=sign*4かつvy/=2
- 地面: ボールはバウンドせずラリー終了。プレイヤーはy=0x120で接地vy=0
- 0x1EB2=abs, 0x1ECE=sign, 0x1EF2=CPU用弾道シミュレータ(同式で先読み)

## 4. 打球初速 (確度: 高) 0x54xx〜0x5Axx。上=[0xEBC] 下=[0xEBE] dir=±1
- トス/レシーブ系(state 0x63, 0x562D): vy = -24 -18*上 +12*下 (→-42/-24/-12)
- スパイク(state 0x62, 0x566E): vy = -38 -4*上 +8*下 (→-42/-38/-30)、vx = (7+左右入力-補正)*dir (±6〜8)
- 通常ヒット(0x56C0): vy = -(キャラ表0xFA値)±補正+16*下、vx = (目標x-現在x) / (2*|vy|/5) …滞空時間から物理逆算 (0x5740-0x5754)
- サーブ後打ち上げ: vy=-32 / -16 (0x48CA/0x48D7)
- 攻撃威力[0x10DA]=キャラ表0x11A値。速度でなく相手スタミナへのダメージ。反射毎に半減(0x623D)
