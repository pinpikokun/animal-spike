# 操作体系の原作回帰・ドライブゲージ・絶対値ダメージ設計

Status: 設計会承認済み (2026-07-20)。実装は未着手。
本仕様は 2026-07-20-special-moves-input-design.md の必殺技入力方式
(D+方向+条件) を前提とし、それ以外の下記項目を上書きする。

## 1. 操作体系 (原作回帰)

原作 VB22.DOC の調査結果に基づく決定。現行の「上+スペース=トス」体系は
廃止する。

### 地上

- 上キー = ジャンプ専用。打球の照準には使わない。
- 地上トス (ボタン+横方向):
  - 後ろ: 自陣後方および真上へトス
  - ニュートラル: 自陣前方へトス
  - 前: 敵陣へ打つ
- レシーブ = 下+ボタン。ダメージ軽減・コントロール不能 (原作準拠)。
  レシーブ上手/下手の付与能力をコントロールのばらつき幅にも効かせて
  よい (リーチ115/85%は既存仕様のまま)。
- 必殺技の「地上で上+D」系は存続。D押下中のジャンプ抑制も存続。

### 空中 (9マス体系)

縦入力で技種、横入力で深さ。横軸の意味は全行で共通
(後ろ=敵陣前面 / なし=敵陣中央 / 前=敵陣後面)。

| 縦入力 | 後ろ | なし | 前 |
|---|---|---|---|
| 下 (アタック) | 敵陣前面へ | 敵陣中央へ | 敵陣後面へ |
| なし (トス) | 敵陣前面へトス | 敵陣中央へトス | 敵陣後面へトス |
| 上 (ブロック) | ブロック | ブロック | ブロック |

- 空中の上+ボタンは横方向に関係なくすべてブロック。これによりブロックは
  明示入力となり、パッシブ発動 (タスク#47の暴発問題) を撤去する。
- ブロックの打ち分け (シャット/ワンタッチ) は将来の拡張枠として予約。
  第1弾では全部同じブロック。
- 懸念として記録: この体系では空中から自陣へつなぐ手段がない。
  プレイして「つなぎたいのにつなげない」と感じたら、ワンタッチブロック
  (上+後ろ) を受け皿として検討する。事前には対策しない。

## 2. アタック速度

- ジャストアタック: 150% → 110%。人間の反応で取れる速度にするのが目的。
- 通常アタック: 100% → 80%。ジャストとの見た目のギャップ確保。
- どちらもパラメータであり、画面で見て最終調整する。80%が弱すぎる場合は
  引き上げる。

## 3. ドライブゲージ

2本目のゲージ (現・未使用) をドライブゲージとする。変数名は実装時に相談
(1本目=耐久ゲージの変数名も体力を連想させる名前に、実装時に相談)。

### 基本

- 6本で満タンスタート。試合を通して継続し、得点でのリセットはしない。
- 自然回復: 1本あたり約3秒。ただし回復が進むのはラリー中のみ。
  サーブ保持中と得点間インターバル中は回復停止 (遅延戦術の防止)。
- 積極行動 (アタック、ブロック等) で回復速度が上がる。

### 消費と削り

| 行動 | 自分の消費 | 受けた相手の削り |
|---|---|---|
| 通常アタック | 0 | 1本 |
| ジャストアタック | 0.5本 | 2本 |
| トス | 0 | 削られない |
| ブロック / アタック返し | 0 | 削られない |
| 必殺技 | カタログ記載 (帽子1 / ヒップ2 / 炎3) | 削らない |

- 必殺技は相手のドライブゲージを削らない (お邪魔系と攻撃系で削りの
  一貫性が取れないため)。
- マリオ帽子は耐久消費からドライブゲージ1本消費へ変更。
- マリオのヒップアタックは「空中で下+D」の明示入力に変更し、ゲージ2本。
  着地で地震が起き、画面が一瞬揺れて敵味方とも一瞬動けなくなる。

### ジャストレシーブ

- トリガー: 下レシーブ + タイミング一致。移動しながらのお手軽発動を
  防ぐため、構え (下レシーブ) を経由した場合のみ成立する。
- 効果: そのレシーブによるドライブゲージ削りとガード削りを無効化する。
  回復は一切しない (ゲージも耐久も)。削った側の成果は戻らない
  (ラチェット原則)。
- 演出必須: ヒットストップ+専用フラッシュ+専用SE。発動が視認できない
  報酬は報酬ではない。

### バーンアウト

- ドライブゲージが0になると発生。
- 効果: 必殺技・ジャストアタック・ジャストレシーブがすべて使用不能。
  さらに被ガードダメージ1.5倍 (乗算、int演算 *3/2)。
- 復帰: ラリー実時間で10秒経過すると6本全回復。回復停止ルールは
  バーンアウト中も同じ (ラリー中のみ進む)。
- 10秒は暫定値。KPIハーネスで平均ラリー時間を実測し、
  「バーンアウト=約Nラリー」で語れるようにしてから最終決定する。
  抑止力の本体は時間ではなく「ジャスト系封印+被ダメ増で、いつスタン
  させられてもおかしくない危険」である。

### サーブルール変更

- サーブトスに触れなかった場合の「点数なしやり直し」を廃止。
  サーブトスを上げて打てなかったら相手の得点+相手ボールにする。

## 4. ダメージの絶対値化

%表記を廃止し、すべて絶対値で語る。simはint専用なので丸め問題も消える。

### 耐久 (GUARDランク)

A=120 / B=110 / C=100 / D=90 / E=80

### ジャストアタックの削り (攻撃側POWERランク)

A=35 / B=30 / C=25 / D=20 / E=15

- 通常アタックは従来どおり削りなし (パワーボール化しない)。
- 標準戦 (C対C) は4発でスタン。最重対最軟3発、最軽対最硬8発。
- 数値は全部データ駆動パラメータ。表の構造原則
  (刻み一定 / 攻の差 > 守の差) だけを固定する。

### 気絶のボタン連打短縮 (原作準拠、2026-07-20採用)

- 気絶中にボタンを連打すると解除が早まる (原作VB22.EXE実装:
  気絶カウンタ125tickに対し押下ごとに+3加速)。
- 具体的な加速量はパラメータとしてデータ駆動にする。
- 気絶を「待つだけの時間」から「あがく時間」に変える。表示層は
  連打が効いていることが分かる演出 (揺れ加速等) を添えること。

### 回復の全廃

- ジャストトス/ジャストレシーブによるガード回復 (guard_heal_just 相当)
  を撤去する。削りは不可逆 (ラチェット)。試合は必ず決着に向かう。

### 倍率の重なり

- 倍率は乗算・int演算・上限なし。極端な重なり (例: 防御不能技×
  バーンアウト1.5倍で即スタン) は事故ではなく見せ場として意図する。
- バーンアウト1.5倍は必殺技のダメージにも掛かる。

## 5. 必殺技カタログ原則

- 必殺技にジャスト判定はない。出せたら常に同じ技。
- 威力はキャラのステータスに左右されない固定値。カタログに絶対値で書く。
  持ち主のランクは通常技にのみ効く (倍率方式は持ち主のパワーに隠れて
  連動するため廃止)。
- カタログの1行 = 威力 / ゲージコスト / 発動条件 / 防御分類。
- 防御分類は「見た目の属性」ではなく「防御の仕組み」で行う。
  属性 (炎/雷等) は表示層の演出情報であり、分類には一切使わない。
  同じ炎の見た目でも防げる技を将来作ってよい。
  - 防御不能系: ジャストレシーブで無効化不可。アタック返しのみ技を
    かき消して無傷 (原作VB22.DOC【必殺技攻略法】準拠)。
  - 吹き飛ばし系: レシーブかブロックで防げる (原作: 突風アタック、
    バンブルボール、バブルパック)。
  - 時間差系: ボール消失など (原作: 異次元転送ボール)。
- 殺人燃えるアタック: 威力40 (固定)、ゲージ3本、防御不能系。
  現行の「通常パワー球の2倍」係数と追加スタン盛りは撤去し、役割を
  「ジャスト無効の確定ダメージ+コンボ起点」に一本化する。
  3発ではスタンしない (対耐久C: 40+40=80)。
- 記録: 原作でゴーストボールはカービィの技 (地上で上を押しながら打つ)。
  TOMEへの付与はパイロット実装の借用であり、カービィ実装時に持ち主を
  設計会で再決定する。
