# 操作体系の原作回帰・ドライブゲージ・絶対値ダメージ設計

Status: 実装済み (2026-07-23、全6節を7コミットで実装、329テスト全緑)。
ゲージ変数名は drive_gauge (1本=1000)。耐久ゲージの改名案 guard_durability
は未適用 (ユーザー確認待ち)。
本仕様は 2026-07-20-special-moves-input-design.md の必殺技入力方式
(D+方向+条件) を前提とし、それ以外の下記項目を上書きする。

## 1. 操作体系 (原作回帰)

原作 VB22.DOC の調査結果に基づく決定。現行の「上+スペース=トス」体系は
廃止する。

### 地上

- 上キー = ジャンプ専用。打球の照準には使わない。
- 地上トス (ボタン+横方向):
  - 後ろ: 自陣後方および真上へトス
  - ニュートラル: 自陣前方へトス
  - 前: 敵陣へ打つ
- レシーブ = 下+ボタン。ダメージ軽減・コントロール不能 (原作準拠)。
  レシーブ上手/下手の付与能力をコントロールのばらつき幅にも効かせて
  よい (リーチ115/85%は既存仕様のまま)。
- 必殺技の「地上で上+D」系は存続。D押下中のジャンプ抑制も存続。

### 空中 (9マス体系)

縦入力で技種、横入力で深さ。横軸の意味は全行で共通
(後ろ=敵陣前面 / なし=敵陣中央 / 前=敵陣後面)。

| 縦入力 | 後ろ | なし | 前 |
|---|---|---|---|
| 下 (アタック) | 敵陣前面へ | 敵陣中央へ | 敵陣後面へ |
| なし (トス) | 敵陣前面へトス | 敵陣中央へトス | 敵陣後面へトス |
| 上 (ブロック) | ブロック | ブロック | ブロック |

- 空中の上+ボタンは横方向に関係なくすべてブロック。これによりブロックは
  明示入力となり、パッシブ発動 (タスク#47の暴発問題) を撤去する。
- ブロックの打ち分け (シャット/ワンタッチ) は将来の拡張枠として予約。
  第1弾では全部同じブロック。
- 懸念として記録: この体系では空中から自陣へつなぐ手段がない。
  プレイして「つなぎたいのにつなげない」と感じたら、ワンタッチブロック
  (上+後ろ) を受け皿として検討する。事前には対策しない。

## 2. アタック速度

- ジャストアタック: 150% → 110%。人間の反応で取れる速度にするのが目的。
- 通常アタック: 100% → 80%。ジャストとの見た目のギャップ確保。
- どちらもパラメータ。通常アタック80%の手触りは問題なし
  (2026-07-23実機確認)。

## 3. ドライブゲージ

2本目のゲージ (現・未使用) をドライブゲージとする。変数名は実装時に相談
(1本目=耐久ゲージの変数名も体力を連想させる名前に、実装時に相談)。

### 基本

- 6本で満タンスタート。試合を通して継続し、得点でのリセットはしない。
- 自然回復: 1本あたり約4秒 (240tick)。ただし回復が進むのはラリー中のみ。
  サーブ保持中と得点間インターバル中は回復停止 (遅延戦術の防止)。
- ゲージが減った直後3秒 (180tick) は自然回復が停止する。消費の重みを保つため
  (2026-07-23決定)。ディレイもラリー中のみ進む。
- 積極行動 (アタック、ブロック等) で回復速度が上がる。
- ジャストアタック判定はリーチの45%以内
  (2026-07-23実機確認で60%から縮小)。ジャストレシーブは位置の芯判定を使わない。

### 消費と削り

| 行動 | 自分の消費 | 受けた相手の削り |
|---|---|---|
| 通常アタック | 0 | 1本 |
| ジャストアタック | 0.5本 | 2本 |
| トス | 0 | 削られない |
| ブロック / アタック返し | 0 | 削られない |
| 必殺技 | カタログ記載 (帽子1 / ヒップ2 / 炎3) | 削らない |

- 必殺技は相手のドライブゲージを削らない (お邪魔系と攻撃系で削りの
  一貫性が取れないため)。
- 必殺技はスト6式の使い切り制。ゲージが1でも残っていれば発動でき、
  カタログコストに不足していても残量をすべて消費して0となり、バーンアウトへ
  突入する。ゲージがちょうど0のときだけ発動不可。ジャストアタック0.5本も
  同じく下限0で止まり、不足していても成立する。
- マリオ帽子は耐久消費からドライブゲージ1本消費へ変更。
- マリオのヒップアタックは「空中で下+D」の明示入力に変更し、ゲージ2本。
  着地で地震が起き、画面が一瞬揺れて敵味方とも一瞬動けなくなる。

### ジャストレシーブ

- トリガー: 地上で静止中 (横入力なし・vx=0) に下+ボタンを押した瞬間から
  10tick (`just_receive_window_ticks`) のタイミング窓を開く。窓内に相手の
  攻撃球をレシーブすると成立し、位置の芯判定は行わない。
- 押しっぱなしでは窓を再設定しない。窓切れ後は通常レシーブとなり、
  一度離して押し直したときだけ新しい窓を開く。旧「構え維持」方式は廃止
  (2026-07-24実機フィードバックによる再設計)。
- 効果: そのレシーブによるドライブゲージ削りとガード削りを無効化する。
  回復は一切しない (ゲージも耐久も)。削った側の成果は戻らない
  (ラチェット原則)。
- 演出必須: 10tickのヒットストップ、成立直後6tickだけの低彩度な水色ティント、
  頭上に約30tickの「JUST!」表示、専用SE。画面全体の白フラッシュと
  長時間の白→青発光は、実機で眩しいというフィードバックにより撤去した
  (2026-07-25減光)。発動の視認性はヒットストップと「JUST!」で担保する。

### バーンアウト

- ドライブゲージが0になると発生。
- 効果: 必殺技・ジャストアタック・ジャストレシーブがすべて使用不能。
  さらに被ガードダメージ1.5倍 (乗算、int演算 *3/2)。
- 復帰: ラリー実時間で10秒経過すると6本全回復。回復停止ルールは
  バーンアウト中も同じ (ラリー中のみ進む)。
- 10秒は暫定値。KPIハーネスで平均ラリー時間を実測し、
  「バーンアウト=約Nラリー」で語れるようにしてから最終決定する。
  抑止力の本体は時間ではなく「ジャスト系封印+被ダメ増で、いつスタン
  させられてもおかしくない危険」である。
- 表示はキャラ本体の灰色ティント+周期点滅、ゲージ枠の赤点滅と
  「BURNOUT」表示、突入瞬間の専用フラッシュ+短いヒットストップを必須とする。

### サーブルール変更

- サーブトスに触れなかった場合の「点数なしやり直し」を廃止。
  サーブトスを上げて打てなかったら相手の得点+相手ボールにする。

## 4. ダメージの絶対値化

%表記を廃止し、すべて絶対値で語る。simはint専用なので丸め問題も消える。

### 耐久 (GUARDランク)

A=120 / B=110 / C=100 / D=90 / E=80

### ジャストアタックの削り (攻撃側POWERランク)

A=35 / B=30 / C=25 / D=20 / E=15

- 通常アタックは従来どおり削りなし (パワーボール化しない)。
- 標準戦 (C対C) は4発でスタン。最重対最軟3発、最軽対最硬8発。
- 数値は全部データ駆動パラメータ。表の構造原則
  (刻み一定 / 攻の差 > 守の差) だけを固定する。

### 気絶のボタン連打短縮 (原作準拠、2026-07-20採用)

- 気絶時間は4秒 (240tick、2026-07-25決定)。旧180tickは連打短縮を
  採用する前の値だったため、連打短縮導入後の基準時間として見直した。
- 気絶中にボタンを連打すると解除が早まる (原作VB22.EXE実装:
  気絶カウンタ125tickに対し押下ごとに+3加速)。
- 具体的な加速量はパラメータとしてデータ駆動にする。
- 気絶を「待つだけの時間」から「あがく時間」に変える。表示層は
  連打が効いていることが分かる演出 (揺れ加速等) を添えること。

#### 行動不能時間をこの値にした理由 (2026-07-25)

これを書き残さないと、次に触る人が同じ議論をやり直すことになる。

原作VB22.EXEの設計値と、本作の採用値の対応:

| 状態 | 原作の設計値 | 原作の推定秒数 | 本作の採用値 |
|------|------------|--------------|------------|
| 気絶 | 125コマ | 約4.2秒 | 240tick = 4.0秒 |
| 炎上 | 50コマ  | 約1.7秒 | 90tick = 1.5秒 |
| 感電 | 35コマ  | 約1.2秒 | 60tick = 1.0秒 |
| 泡   | (未実装) | -        | 60tick = 1.0秒 |

- 原作の125/50/35は10や25の倍数で、作者がコマ数側でキリのいい数字を
  選んだと読める。実際の解除は「超えたら」判定なので1コマ多く動く。
- 原作は約30コマ/秒と推定している (実機計測はしていない。EXEの
  ウェイト処理からの推定であり、確定値ではない)。
- 本作は60tick/秒なので、原作の秒数を60tick/秒の側でキリよく丸めた。
  「原作のコマ数を2倍する」のではなく「原作の秒数に寄せる」を採った。
  原作準拠を秒で守り、数字は本作の解像度でキリよくする方針。
- 気絶を180tick(3秒)から240tick(4秒)へ上げたのは、180が連打短縮を
  入れる前の値だったため。連打で最短1.6秒まで縮むので、
  あがかない場合の4秒は原作の体感に近い。
- 炎上・感電・泡には連打短縮を適用しない。原作でも解除操作は無く、
  「食らったら何もできない」ことが技の価値だから。

#### 原作と意図的に異なる点 (2026-07-25ユーザー判断)

- 気絶時に壁際まで吹っ飛ばす演出は、本作独自のものとして残す。
  原作の気絶ハンドラ0x72EAは慣性スライド、摩擦、重力、床クランプのみで、
  壁まで飛ばす処理を持たない。本作には原作にない耐久ゲージがあるため、
  その決着に見せ場を作る意図的な逸脱である。実装は
  `hit_resolver.gd` の `PUSH_STUN_TICKS` が担う。
- 原作は炎上明けに気絶へ移行するとき、気絶カウンタを15進めた状態から
  始めるため、通常の気絶より約0.5秒短い。本作はこの短縮を採用せず、
  炎上明けも通常どおり240tickの気絶を全時間適用する。ユーザー判断による
  原作仕様の不採用であり、カウンタ15を実装へ追加してはならない。
- 炎上被弾の打ち上げ高さは80px (`burn_launch_height_px`)。ネットの高さ45pxの
  1.75倍にあたり、原作の0.65倍より約2.7倍高い。派手さを優先したユーザー判断。

  換算の落とし穴を記録する。原作は縦と横で座標スケールが異なる。
  横はコート幅144座標に対し本作448pxで3.11px/座標、縦はネット高さ33座標に対し
  本作45pxで1.36px/座標。打ち上げは縦の量なので、横の倍率で換算すると
  65pxという誤った値が出る (2026-07-25に一度この誤りを犯した)。
  座標単位に依存しない「ネット高さとの比」で比較すること。
  原作の打ち上げ頂点は初速16・重力6から 16^2/(2*6) = 21.3座標、
  ネット高さ33座標に対し0.65倍である。

  副作用として、80pxでは炎上1.5秒の間に床バウンドが収束しない。
  本作の重力は原作の約6分の1しかなく (原作を本作単位へ直すと約2.05px/tick^2、
  本作は0.32px/tick^2)、高く上げるほど2/3減衰が終わらないため。
  実測では45px以下なら炎上中に接地へ収束し、55px以上では最後まで
  跳ね続けて炎上明けの瞬間も空中にいる。80pxは後者を承知の上での採用。
  「炎上明けに床へ伏せた姿を見せたい」を優先するなら35px前後へ下げること
  (実測: 35pxで1.23秒に収束し、伏せた姿が0.28秒見える)。

### 回復の全廃

- ジャストトス/ジャストレシーブによるガード回復 (guard_heal_just 相当)
  を撤去する。削りは不可逆 (ラチェット)。試合は必ず決着に向かう。

### 倍率の重なり

- 倍率は乗算・int演算・上限なし。極端な重なり (例: 防御不能技×
  バーンアウト1.5倍で即スタン) は事故ではなく見せ場として意図する。
- バーンアウト1.5倍は必殺技のダメージにも掛かる。

## 5. 必殺技カタログ原則

- 必殺技にジャスト判定はない。出せたら常に同じ技。
- 威力はキャラのステータスに左右されない固定値。カタログに絶対値で書く。
  持ち主のランクは通常技にのみ効く (倍率方式は持ち主のパワーに隠れて
  連動するため廃止)。
- カタログの1行 = 威力 / ゲージコスト / 発動条件 / 防御分類。
- 防御分類は「見た目の属性」ではなく「防御の仕組み」で行う。
  属性 (炎/雷等) は表示層の演出情報であり、分類には一切使わない。
  同じ炎の見た目でも防げる技を将来作ってよい。
  - 防御不能系: ジャストレシーブで無効化不可。アタック返しのみ技を
    かき消して無傷 (原作VB22.DOC【必殺技攻略法】準拠)。
  - 吹き飛ばし系: レシーブかブロックで防げる (原作: 突風アタック、
    バンブルボール、バブルパック)。
  - 時間差系: ボール消失など (原作: 異次元転送ボール)。
- 殺人燃えるアタック: 威力40 (固定)、ゲージ3本、防御不能系。
  「通常パワー球の2倍」係数は撤去したまま、炎上による完全行動不能を持つ。
  3発ではスタンしない (対耐久C: 40+40=80)。
- 炎上の行動不能は1.5秒 (90tick)、連打短縮なし。
  2026-07-25の逆アセンブルで、原作の炎上は状態8・50コマの間、
  入力・打撃・ボール接触を一切行わず慣性・摩擦・重力だけで動く状態だと確定した。
  旧方針の「追加スタンを盛らない」は原作調査前の独自判断であり、
  ユーザー判断「原作の技なので原作に合わせる」により撤回する。
- 未実装技の確定値: サンダーボール (カービィ) の感電は1秒 (60tick)、
  バブルパック (デュオ) の泡は1秒 (60tick)。どちらも連打短縮なし。
  該当キャラの実装時にこの値を使用する。
- 記録: 原作でゴーストボールはカービィの技 (地上で上を押しながら打つ)。
  TOMEへの付与はパイロット実装の借用であり、カービィ実装時に持ち主を
  設計会で再決定する。
