# ジャンプ高度とウェイト物理 設計

## 目的

キャラクターのジャンプ値とウェイト値を分離し、低ジャンプキャラも攻撃へ参加でき、高ジャンプキャラも画面内に収まる物理へ調整する。

## ジャンプ高度

- 高度はキャラクター画像の頭ではなく、シミュレーション上の足元座標で測る。
- 測定対象はジャンプボタンを押し続けたフルジャンプの最高点とする。
- ジャンプレベル1は、床から背景横線3本分の高さへ到達する。
- ジャンプレベル5は、床から背景横線5本分の高さへ到達する。
- ジャンプレベル10は、床から背景横線7本分の高さへ到達する。
- レベル1から5、レベル5から10の間は、それぞれ線形補間する。
- 背景横線の間隔は24pxとして物理値へ変換する。
- 小ジャンプ操作は維持し、ジャンプボタンを早く離した場合は最高点より低くなる。

## ウェイトと滞空時間

- ウェイトはフルジャンプの到達高度を変えない。
- ウェイトは頂点へ到達するまでの上昇時間と、頂点から着地するまでの下降時間を変える。
- ウェイト5を現行の標準時間100%とする。
- ウェイト1は上昇時間115%、下降時間125%とする。
- ウェイト10は上昇時間85%、下降時間80%とする。
- 中間レベルは線形補間する。
- 重いキャラクターほど素早く上昇し、素早く下降する。
- 軽いキャラクターほどゆっくり上昇し、ゆっくり下降する。
- 上昇初速と上昇重力は、指定された高度と上昇時間の両方を満たすように算出する。
- 下降重力は、指定された高度と下降時間を満たすように算出する。

## 既存挙動との境界

- 移動速度、アタック威力、トス、レシーブ、吹っ飛ばされにくさは今回変更しない。
- ウェイトによる吹っ飛ばされにくさは既存挙動を維持する。
- ヒップアタック、壁張り付き、硬直中の専用速度処理は今回のジャンプ計算から除外する。
- シミュレーションは整数固定小数点と決定論を維持する。

## 実装方針

キャラクター定義は引き続き10段階の `jump` と `weight` を保持する。`chars.gd` はレベル値を返し、`simulation.gd` が目標高度、上昇時間、下降時間からフレームごとの初速と重力を算出する。描画上のスプライト寸法は物理計算へ入れない。

## テスト

- レベル1、5、10のフルジャンプ最高点が、それぞれ72px、120px、168px付近になること。
- 同じジャンプレベルなら、ウェイト1、5、10で最高点が一致すること。
- ウェイト1、5、10で上昇時間と下降時間が指定順になること。
- ジャンプボタンを早く離すとフルジャンプより低くなること。
- 全キャラクターが画面内で着地し、既存の同期・決定論テストを壊さないこと。

整数刻みのため、最高点と時間には1フレームまたは固定小数点丸め相当の許容差を設ける。
