# i18n (多言語対応) ポリシー

Status: 承認済み・実装は保留 (2026-07-20 設計会)

## 決定事項

- 今すぐ翻訳作業はしない。実装するのは「仕組み」のみで、時期は別途判断
  (遅くとも Steam ストア準備前)。
- sim 層は数値のみの世界であり i18n の影響を受けない。対象は表示層と UI
  テキストだけ。

## 方針

1. プレイヤーに見える文字列 (キャラ名、能力名、必殺技名、UI ラベル、
   ステータス表記) は 1 か所の文字列テーブルに集約する。コード各所への
   ベタ書きを禁止する。
2. 翻訳機構は Godot 標準の翻訳システム (CSV ベースの Translation) に乗る。
   独自機構は作らない。
3. 完備性テストを添える: 全キー (全キャラ・全能力・全必殺技) が
   テーブルに存在することをテストで強制する。登録漏れ時の静かな
   フォールバック (別言語や空文字の黙殺) は禁止し、警告を出す。
   顔アイコンで起きた「正本が割れて登録漏れが再発する」問題の文字列版を
   防ぐため。

## やらないこと

- 音声・画像内テキストの翻訳 (当面スコープ外)
- 実際の英語訳の執筆 (仕組み導入とは別タスク)
