# 人間向け標準トス高さ設計

作成日: 2026-07-30

Status: 設計は承認済み。680px/sは未確定の初回試遊値であり、試遊後に最終値を決める。

## 1. 目的

味方が上げる標準トスを、人間が見てから移動し、余裕を持ってアタックできる軌道へ変更する。
CPUが処理できることではなく、人間がプレイして気持ちよいことを合格基準にする。

## 2. 現状の証拠

現行の味方地上トスは `bump_up_speed_px_s = 520` を地上レシーブと共用している。
現行と同じ固定小数・更新順で単独軌道を測定した結果は次のとおり。

| 対象 | 初速 | 上昇量 | 頂点まで | 接触高へ戻る概算 |
|---|---:|---:|---:|---:|
| 現行の味方地上トス | 520px/s | 113.250px | 28tick / 0.467秒 | 0.933秒 |
| キャラクターのジャンプ | - | 100 / 120 / 135 / 145 / 155px | - | - |

`bump_up_speed_px_s` は 2026-07-13 のコミット `1747977` で620から520へ下げられた。
理由は、入射速度の慣性反射を含むレシーブを画面内へ収めるためだった。
現行では地上レシーブだけが縦の入射慣性を受け、味方地上トスは固定初速を使う。
したがって、両者が同じ値を共有し続ける必要はない。

## 3. ユーザー決定

- 今回は全キャラクター共通の標準トスだけを扱う。
- CPU難易度は考慮しない。
- `トス上手`、`トス下手` などのパッシブ能力を標準トスの高さ決定に適用しない。
- 30%で低いトスになる既存処理も標準トスには適用しない。
- この変更により `トス下手` の低トス効果は一時的に発生しなくなる。能力の定義だけを残し、
  実効化または撤去は将来の速攻タスクで再設計する。
- 低いトスは上級者向け速攻として将来タスクへ分離する。
- 実際の気持ちよさは試遊しないと確定できないため、680px/sは初回試遊値とする。

## 4. 採用方式

`data/rules.json` に味方地上トス専用の `ally_ground_toss_up_px_s` を追加する。
初回試遊値は680とする。`SimConfig` はこの値を固定小数のtick単位へ変換し、
味方へ上げる1打目・2打目の地上トスだけが使用する。

現行と同じ更新順で680px/sを単独測定すると、上昇量は195.418px、頂点は36tick、
0.600秒、接触高へ戻る概算は1.200秒となる。この数値は最終仕様ではなく、
初回試遊時の再現基準である。

試遊後の調整は `ally_ground_toss_up_px_s` だけを変更する。レシーブや他の打球値を
連動させない。

## 5. 適用条件

次をすべて満たす打球にだけ専用値を適用する。

1. 地上トスである。
2. 味方側を目標にするトスである。
3. 実装上の `returns_to_opponent == false` を満たす。
4. 打数または入力方向によって相手コートへ返す球ではない。
5. サーブではない。

左右どちらのチーム、どのキャラクターでも同じ初速を使用する。

## 6. 変更しないもの

- 地上レシーブの `bump_up_speed_px_s = 520`
- 空中トスの `toss_fwd_vy_px_s = 470`
- 3打目の相手コート返球
- サーブトスの `serve_toss_up_px_s = 620`
- 横方向の目標Xを決める `toss_target_x`
- 重力、ジャンプ、移動、リーチ
- CPUの判断と難易度
- パッシブ能力の定義そのものと、`トス上手` の既存の横照準効果。ただし `トス下手` の
  低トス効果は一時的に発生しない

トスの滞空時間が変わるため、目標Xへ着地させる横初速は `toss_aim_vx` で再計算する。
目標Xは変えない。既存の低トス処理は将来の再設計候補として残してよいが、今回の
標準トス経路からは呼ばない。

## 7. 検証

### 7.1 契約テスト

- 両チームの1打目・2打目で、味方側を目標とする地上トスが
  `-ally_ground_toss_up` で上がる。
- 全キャラクターで同じ縦初速になる。
- `トス下手` の固定抽選値でも標準トスの縦初速が変わらない。
- 3打目の返球、地上レシーブ、空中トス、サーブトスの既存値が変わらない。
- 680px/sの単独軌道を実際のボール物理で進め、上昇量195px以上196px未満、
  頂点36tickになる。
- 地上レシーブの単独軌道は上昇量113px以上114px未満、頂点28tickのままとする。
- 空中トス470px/s、サーブトス620px/s、3打目返球の既存契約値を固定期待値で守る。
- テスト用設定で `ally_ground_toss_up_px_s` だけを別値へ差し替え、対象の標準トスだけが
  追従し、対象外の四経路が追従しないことを確認する。

### 7.2 全件検証

正規入口 `run_tests.ps1` を全件実行する。固定値・配列・ゴールデンハッシュに変化が出た場合は、
標準トスの意図した入力列変化か、対象外の回帰かを分けて報告する。対象外の変化は停止条件とする。
CPUの設定値と判断ロジックは変更しない。標準トスの高さ変更に伴う位置取り、入力列、ラリー結果の
変化は想定内だが、得点不能、返球不能、ラリー不成立が生じた場合は停止する。

### 7.3 人間の試遊

自動テスト合格後、ユーザーが実際にプレイする。次を確認する。

- 味方トスを見てから移動してアタックへ入れるか。
- 標準トスに余裕があり、成功時に気持ちよいか。
- 高すぎる、遅すぎる、待たされる感覚がないか。

680px/sはこの試遊の開始値であり、試遊を通るまで最終値およびタスク完了とは扱わない。

## 8. 停止条件

- 地上レシーブ、空中トス、3打目返球、サーブトスの軌道が変化した。
- 標準トスの変化だけでは説明できない得点不能、返球不能、ラリー不成立が発生した。
- パッシブ能力やCPU難易度を今回の判断へ混ぜる必要が生じた。
- 専用値一つでは人間向けの高さとテンポを両立できない。
- 試遊で高すぎる、低すぎる、遅すぎると判断された。

停止時は原因と実測値を報告し、専用値の再調整または別設計を相談する。

## 9. 将来タスクとの境界

低いトスは、意図して使う上級者向け速攻として別タスクで設計する。
今回の標準トスへランダムな低下や難易度差を戻さない。
