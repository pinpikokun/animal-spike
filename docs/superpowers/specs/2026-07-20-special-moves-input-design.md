# 必殺技の入力方式(設計会決定 2026-07-20)

ユーザー承認済みの決定事項。実装後にプレイして最終判断する(暫定運用)。

## 決定: 全必殺技はDボタン(必殺ボタン)+方向で発動する

- スト6モダンのSPボタンと同思想。「必殺技を出す」というプレイヤーの意思を
  ボタンで明確に取る。条件が揃ったら勝手に出る方式(原作の高度条件等)は不採用
- 原作の「押し打ち/離し打ち」分岐は実装しない。1ボタン時代の制約の産物であり、
  D+方向で入力空間は足りる(この決定により保持状態管理の土台工事が不要になる)
- マリオの帽子投げ(D)と同じ文法に統一: D=固有技/必殺技ボタン
- 入力ビットは予約済みのIN_ABILITYスロットを使う(アーキ移行T3)

## 難易度の考え方

- 入力実行は易しく、状況作りと使い所で差が出る(トスを上げ落下点に入り高所でD、
  という「お膳立て」が実行難度に相当する)
- ジャストミートと重ねた場合の威力ボーナス等、「入力は易しく極めるのは難しく」の
  拡張余地を残す

## 保留(別途設計会)

- ゲージ制(消費量・回収手段・満タン条件)。ユーザーが構想中。当面はゲージ無しで
  技を素出しできる状態でプレイ感を検証する
- 各キャラの技の効果詳細・威力・硬直(1キャラずつ設計会で決める)

## パイロット実装: トメ(カエル)の2技

プレイ判断用の先行実装。効果は最小構成で作り、手触り確認後に調整する。

| 技 | 入力 | 効果(最小構成) |
|---|---|---|
| ゴーストボール | 地上で上+D+打球圏内 | 打球が相手コートへ渡るまで表示層で点滅消失(simは通常軌道=決定論に影響なし) |
| 殺人燃えるアタック | 空中でネット上端より高い位置+下+D+打球圏内 | パワーボール強化版: レシーブ/ブロックでもガードダメージ(通常パワー球の2倍)。アタックで打ち返すと効果消滅して通常球に戻る |

- 発動にゲージ条件なし(暫定)。打球圏外でDを押しても何も起きない(空振りなし)
- 表示: 燃えるアタックはBALL.DATの炎球スプライト、ゴーストは点滅で代用可
