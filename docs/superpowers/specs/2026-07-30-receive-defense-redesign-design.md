# 地上トスとレシーブの攻撃球防御差 再設計

Status: 設計確定 - ユーザー決定反映済み。未実装。

## 1. 目的

相手の攻撃球に対し、接地して下+ACTIONのレシーブ構えが成立した場合だけ、
防御選択として機能するようにする。地上トスと飛びつきはレシーブ構えが成立して
いないためガード損害を受ける。ただし、跳躍動作そのものが成立している飛びつきには
接地被弾用のしりもちを重ねない。通常レシーブは制御とドライブを失う代わりに
ガード損害を減らし、ジャストレシーブは現行どおり完全防御とする。

高さ、散り、横っ飛びリーチ、CPU判断、キャラクター能力は変更しない。

## 2. 根拠

### 2.1 原作由来の事実

原作は相手アタックへの接触結果を受け手の状態で分ける。

- 地上トスなど通常接触: 攻撃威力の100%を受け、吹き飛ぶ。
- 下+ACTIONのレシーブ: 攻撃威力の40%を受ける。
- ブロック: 攻撃威力の約50%を受ける。
- 防御不能技: 通常のレシーブ軽減を適用しない。

根拠は `docs/reference/original-vb22-controls-vs-current.md` と
`C:\work\PC98\vb2211-analysis\snippets\func_39c2_ball_hit_damage.asm` の
0.4倍計算である。

### 2.2 現行本作の問題

現行は地上トスが通常レシーブを防御面で支配している。

| 飛来球 | 地上トス | 通常レシーブ | ジャストレシーブ |
|---|---|---|---|
| 通常アタック | drive 0、guard 0 | drive 1本、guard 0 | 両方0 |
| ジャストアタック | drive 0、芯ならguard 0 | drive 2本、guard全量、しりもち | 両方0 |

地上トスは通常レシーブより制御しやすく、ドライブ損害も小さい。ジャストアタックも
芯で触ればガード損害としりもちまで防げる。下入力を選ぶ実戦上の理由が弱い。

### 2.3 本作独自の判断

原作の40%をドライブへ直訳しない。ドライブは回復可能な行動資源、ガードは不可逆な
耐久であり、役割が違うためである。

原作の攻撃威力は気絶まで蓄積するスタミナから減算される。本作で同じ役割を持つのは
気絶まで不可逆に減る `guard` であり、時間回復する `drive_gauge` ではない。したがって
原作の100%対40%はガード損害へ対応させる。ドライブ削りは本作独自の攻防テンポを
作る別契約とする。地上トス、通常レシーブ、ジャストレシーブは現行値を維持し、
飛びつきは入力にかかわらず地上トスと同じ0へ変更する。

本作では次の交換条件を採用する。飛びつきは入力意図ではなく、接触時に安定した
レシーブ構えを取れているかで分類する。

- 地上トス: ドライブを守り、狙ったトスを出せるが、ガード損害と被弾硬直を受ける。
- 飛びつき: 通常リーチ外の球を救済できるが、構えが間に合っていないためドライブを
  消費せず、ガード損害は地上トスと同じになる。ただし跳躍中に接地用のしりもちへ
  遷移させず、飛びつき動作を継続する。低い軌道と散りは維持する。
- 通常レシーブ: ドライブを失い、球も散るが、ガード損害を40%へ減らし、
  ガードブレイクしない限り吹き飛ばない。
- ジャストレシーブ: タイミング成功報酬として両方を防ぐ。

これにより地上トスは危険な選択として残り、完全な禁止入力にはしない。飛びつきも
届かなかった球をつなぐ救済であり、防御軽減を得る手段にはしない。

## 3. 入力分類

現行分類を変更しない。

- 接地中の下+ACTION: 通常レシーブ。時間窓を満たせばジャストレシーブ。
- 接地中の下なしACTION: 地上トス。左右はトス方向を選ぶ。
- 通常リーチ外の対象球へのACTION押下: 下入力の有無を問わず横っ飛びを開始する。
- 横っ飛び成功: 地上トスと同じドライブ・ガード損害。しりもちにはならず、
  ジャストレシーブにもならない。

通常リーチ内では相手球へ自動でレシーブを選ばない。明示入力の選択をゲーム性として
残す。横っ飛びは緊急接触として入力意図を上書きし、安定したレシーブ構えとは扱わない。

## 4. 通常攻撃球の基礎ガード損害

通常アタックとジャストアタックの双方が、攻撃者のPOWERランクに対応する既存値を
`ball_guard_damage` として保持する。

```text
POWER A/B/C/D/E = 35/30/25/20/15
```

新しい損害表や倍率は追加しない。通常とジャストの差は次で維持する。

- 打球速度。
- 通常レシーブへ与えるドライブ削りが1本か2本か。
- ジャストアタック側の0.5本消費。
- `ball_power` の見た目、壁減衰、ブロック反動。

標準Cの地上トスは4回でガード100を割る。原作標準の約2回より緩く、現行の
4回というジャストアタック耐久基準も変えない。

## 5. 防御結果

以下は相手チームの `BALL_ATTACK_NORMAL` または `BALL_ATTACK_JUST` へ、地上入力から
即時接触した場合、または活動中の横っ飛びが接触した場合に限る。横っ飛び中の
`on_ground=0` は除外条件にしない。同チーム球、通常トス球、サーブ球には適用しない。

### 5.1 地上トスと飛びつき

```text
guard_damage = base_guard_damage
burnout後 = guard_damage * 3 / 2
```

バーンアウトを含む整数除算は式の各ステップで切り捨てる。

- ドライブ削りは地上トス、飛びつきとも0とする。
- 接触位置がスイート範囲内でも防御上の軽減は得ない。
- 地上トスは、ガード損害が正でガードが残れば現行の `FLINCH_TICKS` と
  後方ノックバックを受ける。
- 飛びつきは、ガードが残る限り `flinch`、ノックバック、追加ヒットストップを受けない。
  接触受付と専用水平速度は現行どおり終了するが、`dive` 表示と縦運動は着地まで継続する。
- ガードが0以下なら接触種別を問わず気絶し、ガードを満タンへ戻す。ただし
  ガードブレイク固有の後方初速と壁方向への押し出しはともに0とし、吹き飛びを
  発生させない。飛びつき状態は終了し、現在の縦速度と重力だけで着地する。
- 地上トスの軌道、接触位置、慣性、トス技能による制御は現行どおり解決する。
- 飛びつきの高さ520、散り、入射慣性、リーチ、移動は現行どおり解決する。
- 飛びつき接触でガードブレイクしなかった場合は、接触受付と専用水平速度だけを終了し、
  `dive` 表示と縦運動は着地まで維持する。ガードブレイク時だけ横っ飛び状態を終了して
  気絶へ移る。

地上トスのしりもちは、原作説明書の「アタックをトスなどで受けると吹き飛ぶ」を
本作の既存被弾状態へ対応させる。新しい硬直値は作らず、現行パワー球被弾と同じ
`FLINCH_TICKS=24`、重量補正付き後方初速、3tick以上のヒットストップを使う。
通常レシーブは原作の防御状態なので、ガードブレイクしない限りこの状態へ入らない。
飛びつきは入力時に下を押していても構えが間に合わなかった結果としてガード損害は
全量受けるが、すでに跳躍している身体へ接地用のしりもちを重ねない。

### 5.2 通常レシーブ

```text
reduced_damage = base_guard_damage * 2 / 5
burnout後 = reduced_damage * 3 / 2
```

40%軽減と、その後のバーンアウト倍率を含む整数除算は式の各ステップで切り捨てる。
POWER A/B/C/D/Eの軽減後は
`14/12/10/8/6`、標準Cのバーンアウト中は `10 * 3 / 2 = 15` となる。

- 通常アタックで1本、ジャストアタックで2本という現行ドライブ削りを維持する。
- ガードが残る限り `flinch`、後方ノックバック、追加ヒットストップを発生させない。
- ガードが0以下なら防御に失敗した決着として気絶し、ガードを満タンへ戻す。
  ガードブレイク固有の後方初速と壁方向への押し出しはともに0とし、吹き飛びを
  発生させない。
- 通常レシーブの散り、操舵、入射慣性と高さは変更しない。

### 5.3 ジャストレシーブ

- ドライブ削り0。
- ガード削り0。
- `flinch`、ノックバック、気絶なし。
- 現行のヒットストップ、JUST表示、効果音、散り0、縦慣性0を維持する。

### 5.4 標準Cの結果表

| 飛来球 | 接触 | drive | guard | 通常しりもち |
|---|---|---:|---:|---|
| 通常アタック | 地上トス | 0 | 25 | あり |
| 通常アタック | 飛びつき | 0 | 25 | なし |
| 通常アタック | 通常レシーブ | -1本 | 10 | なし |
| 通常アタック | ジャストレシーブ | 0 | 0 | なし |
| ジャストアタック | 地上トス | 0 | 25 | あり |
| ジャストアタック | 飛びつき | 0 | 25 | なし |
| ジャストアタック | 通常レシーブ | -2本 | 10 | なし |
| ジャストアタック | ジャストレシーブ | 0 | 0 | なし |

## 6. 例外と優先順位

1. 防御不能分類は本節の通常40%軽減とジャスト無効化より優先する。
2. 炎球などは地上トス、通常レシーブ、ジャスト入力、飛びつきのどれでも、現行どおり
   カタログ固定損害を一度だけ受け、バーンアウト1.5倍と専用被弾を使う。
3. 防御不能球の `ball_attack_kind` が攻撃種別を持つ場合、通常・不成立の
   ジャスト入力は現行どおり1本または2本のドライブも失う。地上トスと飛びつきは
   0のまま。
   現行の炎球は `BALL_ATTACK_NONE` なので、どの入力でもドライブを削らない。
4. ブロック、空中トス、アタック返しの防御経済は変更しない。アタック返し球は
   `ball_attack_kind=BALL_ATTACK_NONE` の既存パワー球として旧分岐を使い、地上で
   通常レシーブしても本節の40%軽減対象にはしない。
5. 壁などで攻撃属性を失った球は通常球として扱い、ガードとドライブを削らない。
6. 同一接触で通常攻撃防御と既存パワー球被弾を二重適用しない。

## 7. 状態遷移と実装境界

- 通常・ジャストアタック成立時に、攻撃者のPOWERランクから既存の
  `power_guard_damage_for_rank` を読み、`ball_guard_damage` へ保存する。
- `ball_power` はジャストアタック固有の表示・物理フラグのままにする。
- 地上接触時は、入力意図と `just_receive` を確定してから一度だけ防御結果を解決する。
- 活動中の横っ飛びが接触した場合は、開始入力の下の有無や接触時に内部付加される
  `IN_DOWN` を参照せず、飛びつき結果として地上トスと同じ防御損害を一度だけ解決する。
- 現行 `_apply_hit` のパワー球被弾分岐とは、`ball_power=1` の相手球に対し、
  スイートなら損害を防ぎ、芯外しならガード全量、`FLINCH_TICKS`、重量補正付き
  ノックバック、ガードブレイク時の気絶を適用する処理を指す。
- 新しい通常攻撃防御は、地上トス、通常レシーブ、横っ飛び、ジャストレシーブについて、
  この既存パワー球被弾分岐を置き換える。処理済みフラグをローカル派生値として持ち、
  同一接触で旧分岐を重ねない。
- 新しい防御分類は接地判定そのものではなく「地上トス、通常レシーブ、
  ジャストレシーブ、飛びつき」という接触種別へ分け、損害と被弾反応を種別から
  決める。#70ではこの分類へ空中接触を追加できる境界を保つ。
- 新分岐でも、既存パワー球を芯外しで受けた場合の `mangled`、狙い30%、
  入射慣性全反射は維持する。防御損害の変更へ返球制御の変更を混ぜない。
- 空中接触、ブロック、防御不能分類は置換対象にせず、既存分岐を使う。
- 打球後は現行どおり攻撃種別、ガード損害、防御分類を消費する。
- 直列化フィールドは追加しない。

## 8. 表示

- 地上トス成功中は現行の `ground_swing` を使う。
- `hit_kind=0` の接地レシーブ成功中は既存の `receive_stance` を使い、地上トスと
  見分けられるようにする。
- 飛びつきはガードが残る限り現行の `dive` 表示を着地まで維持する。
  ガードブレイク時だけ気絶表示を優先する。
- ジャストレシーブは通常レシーブ姿勢に現行のJUST表示を重ねる。
- 新しい画像、ゲージ、効果音は追加しない。

## 9. 守る不変条件

- 下+ACTIONと下なしACTIONの分類を変えない。
- 通常・ジャスト・飛びつきレシーブの高さを変えない。
- 飛びつき開始時の下入力の有無で、防御結果を変えない。
- ガードは自然回復せず、ブレイク時だけ満タンへ戻る。
- ガードブレイクでは気絶するが、ブレイク固有の後方初速と壁方向への押し出しは
  発生させない。
- ドライブの回復、バーンアウト、攻撃別1本/2本削りを変えない。
- 防御不能、ブロック、空中接触の既存結果を変えない。
- 能力値、CPU難易度、乱数で損害率を変えない。

## 10. 検証

- POWER AからEまで、地上トスと飛びつきが基礎値全量、通常レシーブが
  `14/12/10/8/6`、ジャストが0になる。
- 標準Cで通常攻撃とジャスト攻撃の表を全件検査する。
- 地上トスと飛びつきのスイート内外で防御損害が同じになる。
- 下ありと下なしの飛びつきで、guard、drive、しりもちなしが完全一致する。
- 通常レシーブはガードが残る限りしりもちにならない。
- 飛びつきはガードが残る限りしりもちにならず、横っ飛び表示と縦運動を着地まで維持する。
- 各接触でガードブレイクした場合だけ気絶し、決着吹き飛びは起きない。
- ガードブレイク時は `vx=0`、`push=0` となる。飛びつきの `vy` は変更せず、
  重力で着地する。
- バーンアウト時の地上トスと飛びつきの損害をPOWER A/B/C/D/Eで
  `52/45/37/30/22`、通常レシーブを `21/18/15/12/9` と全件検査する。
- 炎球は地上トス、通常、ジャスト入力、飛びつきの全経路で固定40を一度だけ受け、
  炎上し、driveを失わない。バーンアウト時は一度だけ60となる。
- `BALL_ATTACK_NORMAL` を持つ合成防御不能球では、地上トスと飛びつきのdriveは0、
  通常・不成立ジャストは1本だけ削られ、ガード損害は全経路で一度だけ全量となる。
- アタック返し球は `BALL_ATTACK_NONE` のまま旧パワー球経路を通り、今回の40%軽減へ
  入らないことを固定する。
- 通常アタック球でしりもちを受けても、地上トスの軌道と狙いは現行値を維持する。
- ブロック、空中トス、アタック返しの既存回帰を固定する。通常攻撃球のブロックは
  新しい `ball_guard_damage` を保持していてもガードを削らない。
- `hit_kind=0` の接地中だけレシーブ姿勢を表示する。
- `run_tests.ps1` 全件、同期ゴールデン、性能門を通す。

## 11. 承認停止条件

本案は通常アタックにも不可逆ガード損害を追加し、通常レシーブのパワー球損害を
40%へ下げる。本作独自の防御経済を変えるため、次の一括承認を得るまで実装しない。

1. 通常・ジャスト攻撃で同じPOWERランク基礎値を使う。
2. 地上トスと飛びつき100%、通常レシーブ40%、ジャスト0%とする。
3. ドライブ削りは地上トスと飛びつき0、通常レシーブ1本/2本、ジャスト0とする。
4. 地上トスは通常しりもちを受ける。飛びつきと通常レシーブはガードブレイクしない限り
   しりもちにならず、ガードブレイク時も気絶だけで固有の吹き飛びを起こさない。
5. 接地レシーブ成功中は既存レシーブ姿勢を表示する。
