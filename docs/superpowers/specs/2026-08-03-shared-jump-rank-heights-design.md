# 全キャラ共通ジャンプランク高度 設計

日付: 2026-08-03

状態: ユーザー承認済み実装契約

## 1. 決定

原作8キャラを含む全キャラの固有ジャンプ高度を廃止し、ジャンプ能力の
AからEまでの共通ランク表だけで実高度を決める。

| ランク | 足元の目標ジャンプ高度 |
|---|---:|
| A | 200px |
| B | 170px |
| C | 140px |
| D | 120px |
| E | 110px |

UMEは現在と同じEランク110pxを維持する。
UMEの110pxを固有値として残すのではない。UMEの固有 `jump_height_px` も削除し、
既存のEランクを共通表へ引いた結果として110pxになる。

## 2. キャラへの適用

既存のジャンプランク割り当ては変更しない。

| 対象 | ランク | 実高度 |
|---|---:|---:|
| TOME | A | 200px |
| CARBY | B | 170px |
| UME | E | 110px |
| HITO、PIYO、DUO、SEC1、SEC2 | C | 140px |
| パンダ、マリオ、キツネ、カエル | C | 140px |
| その他Cランクのキャラ | C | 140px |

キャラプロフィールの `jump_height_px` 上書き値は全件削除する。
キャラIDから実高度を得る公開窓口 `Chars.jump_height_px(char_id)` は維持し、
内部ではキャラのジャンプランクを共通ランク表へ引き当てる。

## 3. 自然なジャンプ軌道

`JumpArc` の共通重力と高度別軌道を維持する。

- UMEの110pxを共通重力の基準とする。
- UMEは上昇25tick、下降27tickを維持する。
- 各ランクの高さから上昇tick、下降tick、初速を整数で再計算する。
- 高いランクほど滞空時間が長く、低いランクほど短くなる。
- 高度だけを変更して初速や滞空時間を固定しない。
- 早離しジャンプは同ランクのフルジャンプより低くなる。

上昇重力は `2 * 110px / (25 * 24)`、下降重力は
`2 * 110px / (27 * 28)` の16.16固定小数点整数値を全ランクで共有する。
高さ `H` の上昇tick `t` は `g * t * (t - 1)`、下降tick `t` は
`g * t * (t + 1)` が `2 * H` に最も近い整数tickを選び、同差なら長い側を選ぶ。
初速は `(H + g * t * (t - 1) / 2) / (t - 1)` の負値とする。

プレイヤー実動とCPU予測は同じ `Chars.jump_height_px()` と `JumpArc` を使う。
固有高度の撤廃によって両者の軌道を分岐させない。

## 4. 高打点返球の安全帯更新

Aランクを200pxへ変更すると、既存の敵陣返球網羅検査が
距離280px、高さ180px、最大入射、上向き520px/sの左右対称6件で奥壁接触を検出した。
旧返球上限483px/sに対し、同条件の実測安全上限は481px/sだった。

既存の「地上20pxからジャンプ頂点まで、ネットや壁へ当てず敵陣へ返す」契約を維持し、
検査範囲は狭めない。返球下限と入射係数は変更せず、上限の高さ係数だけを
`1/2` から `13/25` へ引き直す。

```text
下限 = 25 + d * 7 / 5
上限 = 248 + d * 9 / 8 - (h - 20) * 13 / 25
上限が下限を下回る場合は 上限 = 下限
```

この変更は高さ20から200pxの範囲で上限だけを0から3px/s下げる。
失敗点は480px/sとなり、安全上限481px/s以内へ1px/sの余裕を持って収まる。
全距離、全高さ、全特性、全入射、左右、2種類の上向き速度の網羅検査を維持する。

## 5. 正本と削除対象

正本は `src/sim/character_profile.gd` の `JUMP_HEIGHT_PX` とする。

削除対象:

- `PROFILES` 内の全 `jump_height_px`
- `Profile.jump_height_px_for_char()`
- 原作画像から換算したキャラ別高度を期待する検査

維持対象:

- ジャンプランク割り当て
- `Chars.jump_height_px(char_id)` の公開API
- `JumpArc` の共通重力、整数計算、更新順序
- CPUが本番と同じ軌道を使う契約

## 6. 非目標

- パワー、スピード、ブレーキ、ガードのランクは変更しない。
- ジャンプランク自体の再割り当ては行わない。
- 重力、早離し率、空中制御、当たり判定は変更しない。
- 原作固有ジャンプ高度は今後の実装根拠にしない。
- 敵陣返球の下限、距離係数、入射係数、上向き速度は変更しない。

## 7. 検証と合格条件

- 共通ランク表が `[200, 170, 140, 120, 110]` と一致する。
- 全選択キャラの実高度が自身のランク表値と一致する。
- TOME、CARBY、UMEの実測足元高度がそれぞれ200、170、110pxの±2px以内になる。
- Cランクの原作キャラと通常キャラが全員140pxの±2px以内になる。
- 同じランクのキャラは同じフルジャンプY列と滞空時間になる。
- UMEは上昇25tick、下降27tick、合計52tickを維持する。
- AからEへ向けて実高度とフルジャンプ滞空時間が単調に短くなる。
- 前項の単調性はA>B>C>D>Eの隣接する全組で厳密に短いことを意味する。
- CPUの空中接触予測と本番1tick後座標が一致する。
- 敵陣返球の既存網羅検査を高さ200pxまで一件も緩めず全件合格させる。
- 正規入口 `run_tests.ps1` が全件合格し、SCRIPT ERRORが0件になる。

## 8. 旧契約の扱い

`2026-08-03-original-character-jump-heights-design.md` のキャラ別高度表は、
本契約によって廃止された履歴資料とする。
自然な共通軌道の設計は本契約へ引き継ぐ。
旧固有高度との同値性は要求しない。値がランク表へ変わること自体が承認済み変更である。
